# Optional V2 — Cross-Project Second Brain

Do not install this just to complete V1.

Add a Second Brain when you have a demonstrated need to reuse validated knowledge across repositories, projects, or AI tools. Until then, `docs/solutions/` plus the repository itself is usually the cheaper source of truth.

Preferred promotion path:

```text
verified work
→ /ce-compound
→ docs/solutions
→ explicitly selected cross-project learning
→ Second Brain inbox/raw source
→ compiled wiki
```

Do not mirror every repo note automatically.
