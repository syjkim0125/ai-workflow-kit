# Olive Young Test Preparation

## What to bring
- `SKILL.md` only, if the assessment rules allow a custom skill/instruction file.
- Do not bring the real-work Second Brain, Jira workflow, Compound notes, or extra automation unless explicitly permitted.

## Pre-test practice
Run at least 3 timed rehearsals on unfamiliar backend repos/problems:
1. feature addition with an existing pattern to extend;
2. bug fix with an edge case/transaction concern;
3. requirement tempting unnecessary abstraction.

After each rehearsal check whether the agent:
- inspected before editing;
- stated acceptance criteria;
- avoided speculative architecture;
- produced focused tests;
- actually ran verification;
- left an interview-ready explanation.

## Environment smoke test
Before test day, verify in the allowed environment:
- the agent discovers `SKILL.md`;
- build/test commands work;
- git diff/status are available;
- the skill does not trigger unrelated workflows or create extra docs.

## Failure signs
Revise the skill if the agent repeatedly:
- generates many new layers/files without evidence;
- rewrites unrelated code;
- spends too long planning before touching a small task;
- claims completion without running tests/build;
- follows a remembered convention instead of the actual repo.
