# 5.4.0 — 2026-11-24

[한국어](5.4.0.ko.md) · English

This release is about cost and time. It was tuned against a plain Claude Code session on real tasks; the results are in [EVALUATION.md](../EVALUATION.md).

- **A direct lane for small changes.** When a request names one behavior and its place, leaves nothing to decide (no parallel copy, nothing to assume or ask), and stays reversible, inside one module, with no external contract, no persistent data and no high-risk area, the agent edits, adds one focused test per stated behavior, runs it and reports. There is no Story, no G1 or G4 and no subagent. Anything left to decide takes the normal path.
- **A shorter normal path** (`skills/workflow/references/fast-path.md`): a strong-tier subagent explores the code and drafts the Story, a mid-tier subagent implements and runs the checks, and a read-only mid-tier subagent reviews once.
- **The graph CLI does the bookkeeping.** `approve G1|G4` writes the approval record from the human's saved reply. `go` turns an approved Story into the first task's brief. `complete` runs a task's checks, records the result and starts the next task. `profile` writes the check profile from `package.json`, `tsconfig.json` or `gradlew`. A passing check is reused for the same code, so final verification does not rerun it.
- **A light lane** for small, reversible, single-module work that still needs a Story: `light`, `check`, `review` and `delivery`, without a full graph run. The Story footer says `Lane: light`.
- **`graph.mjs copies <file-or-folder>...`** lists parallel copies of the code a change touches, such as the same component under sibling brand, platform or locale folders. Whoever drafts the Story runs it first, and the Story covers every copy unless the request names one with a word the code uses for it.
- **Named Gradle tests run in their own module** (`:a:test --tests A :b:test --tests B`). One shared `--tests` list after several tasks used to run every test of the first module and fail the last with "No tests found".
- **Story template v2:** Goal is three lines (As-is, To-be, Unchanged); Decisions come before MUST; `Status`, `Owner` and the gate lines sit in a footer below Verify. The checker still accepts the 5.3.0 order.
- **G4 defaults to an AI summary** in four numbered lines that the human approves explicitly. `human-restatement` stays required for Stories with a G3 decision.
- **One reviewer by default,** two for G3 Stories.

Upgrading from 5.3.0: role graphs and the run format did not change, so a run started under 5.3.0 continues. Run `init` to update the managed `AGENTS.md` and `CLAUDE.md` block and the skills, then open a new session.
